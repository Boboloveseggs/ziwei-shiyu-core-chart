# ZDSM Acceptance Tests

## Test 1 — 强事业 + 弱财帛
输入：
- 官禄核心结构强
- 财帛存在高摩擦结构

必须输出：
- 区分价值生产与价值捕获
不得输出：
- “事业财运一般”

## Test 2 — 禄忌同见
必须：
- 同时描述资源增加与成本黏着
不得：
- 相互抵消

## Test 3 — 单一流日煞曜
若本命/大限/流年无同主题：
必须标记：
- weak_short_term_signal
不得：
- 直接断重大事故

## Test 4 — 小星不能推翻主结构
若主星、三方、四化一致，而单个小星相反：
必须：
- 小星仅作细化
不得：
- 改写主结论

## Test 5 — 去重
同一“合同边界”建议若在事业、钱、合作三处生成：
最终只保留一条最完整建议。
其他章节仅引用。

## Test 6 — 可反证
每个 High/Medium 结论必须有：
- observable indicators
- disconfirming conditions

## Test 7 — 命盘辨识度
每份完整报告至少 3 条：
- 组合特有
- 现实可验证
- 非通用模板

## Test 8 — 年度三层
必须先列：
- 大限
- 小限
- 流年
- 四化
- 各自三方
完整因果链只解释一次。

## Test 9 — 短周期
流月/流日/流时：
只能细化已经存在的年级主题。

## Test 10 — 身体
只能做风险与行为管理：
不得做医学诊断。
