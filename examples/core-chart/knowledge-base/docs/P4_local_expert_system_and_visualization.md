# P4：纯规则专家系统 + 十二宫可视化

## 最终产品原则

主报告生成过程 **0 次 AI API 调用**。

整个系统只依赖：

1. 排盘算法
2. 本地规则数据库
3. 确定性规则代码
4. 报告模板
5. 可视化图引擎

用户看完报告后如果仍有疑问：

> 直接联系人工。

不设置 AI 问答入口，不需要模型 API。

---

## 一、产品的核心不是“算命报告”，而是一张个人系统图

每个人的十二宫都被视为 12 个系统节点。

节点信息：

- 宫位
- 宫干支
- 主星
- 庙旺陷
- 生年四化
- 自化
- 高权重辅煞
- 当前大限/流年/小限/流月/流日/流时激活
- 系统角色
- 关联结论

边分四类：

### T：传统拓扑
- 三合
- 对宫

### M：ZDSM 功能边
例如：
- 命 → 官：行为与能力进入生产
- 官 → 财：成果进入价值交换
- 财 → 田：资源沉淀为长期资产
- 官 → 子：项目转为表达/作品
- 子 → 田：作品沉淀为资产
- 官 → 福 → 疾 → 命：工作—精神—恢复—行动反馈环

### S：流派特定流向
- 自化
- 飞化
- 向心/离心

### Time：时间激活
- 大限
- 流年
- 小限
- 流月
- 流日
- 流时

因此不同人的区别不是“把十二宫文字换一下”，而是：

> 节点不同、节点状态不同、边的性质不同、激活路径不同、瓶颈不同、正反馈回路不同。

---

## 二、视觉层建议

十二宫围成一圈。

每个节点显示：

- 宫位名
- 干支
- 主星
- 庙旺
- 当前激活层

节点标签：

- 发动机
- 中央处理器
- 资源入口
- 输出接口
- 长期资产节点
- 价值捕获瓶颈
- 恢复节点
- 高摩擦节点

边：

- 实线：传统三合/对宫
- 虚线：现代功能链
- 自环：自化
- 高亮：当前时间层

点击宫位后显示详细解释。

---

## 三、人工入口

报告最底部只显示：

“对报告还有疑问？联系人工解读。”

联系方式通过：

`config/contact.json`

配置。

不依赖任何第三方 API。

## 四、完整本地流程

```text
出生资料
↓
排盘器
↓
chart.json
↓
P0/P1 本命规则
↓
P2 时间门控
↓
P3 报告编译
↓
P4 十二宫系统图
↓
报告页面
↓
人工咨询入口
```

全流程可以在你自己的服务器上运行。

---

## 五、这套产品真正的差异化

传统产品：
> 十二宫逐宫写十二段。

ZDSM：
> 先得到个人系统拓扑，再从拓扑生成报告。

例如两个人都可能有“事业宫强”，但：

- A 的瓶颈可能在财帛：会做但不容易留钱；
- B 的瓶颈可能在疾厄：生产能力强但恢复跟不上；
- C 的瓶颈可能在交友：信息很多但机会转化率低；
- D 的瓶颈可能在田宅：做了很多但没有长期沉淀。

所以最终展示的是“我的系统怎么运行”，而不是“十二宫分别什么意思”。
