# ZDSM P5 Monthly Runtime Supplement v1.0

这是给 **P4 Local** 的增量补充包，不需要替换 P4。

目标：

> 把“本月运势”做成网站最高频入口。

P5 不使用 AI API，也不负责重新排盘。

## 输入

- P4 标准 `chart.json`
- 大限
- 流年
- 小限（可选）
- 流月命宫
- 流月四化

## 输出

- 月度运行链
- 流月命宫
- 流月三方四正
- 流月四化
- 多层共振节点
- 核心宫
- 机会承接节点
- 最大瓶颈
- 对宫拉扯
- 身体 / 事业 / 钱 / 爱情关系相关度
- 本月行动
- 月度十二宫可视化数据

## 最重要

本补充包应与 P4 一起交给网站开发 AI。

请首先阅读：

`docs/INSTALL_FOR_WEBSITE_AI.md`
