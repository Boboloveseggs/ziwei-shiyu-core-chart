# 直接交给网站开发 AI

请在现有 **ZDSM P4 Local + P5 Monthly Runtime** 项目中安装这个 **P6 Daily/Hourly Runtime Supplement**。

必须遵守：

1. 不增加任何 LLM / AI API。
2. P6 只做确定性规则运算。
3. 排盘器必须提供流月、流日、流时落宫及各层四化；缺数据不得猜。
4. 新增“今天”和“选择时段”入口。
5. 用户只选日期时分析到流日；选具体时段时再分析流时。
6. 月、日、时必须分别计算三方四正。
7. 展示多层共振、跨层桥接和同星四化过程链。
8. 流日不能推翻流月，流时不能推翻流日。
9. “适合做什么”必须来自最终时段核心宫 + 三方四正 + 用户选择的现实场景，不用固定吉时模板。
10. 底部继续读取 P4 的 `config/contact.json`，只提供人工咨询。
11. 保留 P4 完整命盘和 P5 月运页面。
12. 安装后用 `examples/example_request_2026_10_10_09_11.json` 回归测试，要求识别：
    - 大限福德
    - 流年子女
    - 小限交友
    - 流月夫妻
    - 流日夫妻
    - 流时田宅
    - 月/日夫妻重复激活
    - 日→时存在落入田宅/子女网络的四化桥接
    - 天机形成跨层转换过程
    - 最终时段焦点为田宅：更适合结构化、文档化、方案化、沉淀成果

优先复用 P4/P5 数据库和前端组件，不要复制出第二套十二宫数据。
