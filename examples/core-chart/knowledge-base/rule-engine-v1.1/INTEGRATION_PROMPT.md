# 给本地 AI 的集成任务说明

你收到的是一个名为 `ZDSM Rule Engine V1.1` 的纯前端规则引擎。

## 目标

把该引擎接入我的现有网站，让用户提交已经排好的紫微命盘数据后，
自动生成一个简洁的“人生系统结构图”。

## 必须遵守

1. 不要修改 `src/rules.js` 中的规则含义，除非我明确要求。
2. 不要调用任何 AI API 来决定图的内容。
3. 所有节点、边、摘要必须来自 `analyzeChart(chartJson)` 的输出。
4. 如果我的网站已有排盘能力，只写一个 adapter，把现有排盘结果转换为 `data/chart.schema.json` 的格式。
5. 不要重新实现紫微排盘。
6. 主图只显示 `visibleNodes` 和 `edges`。
7. `hiddenEdges` 默认不显示，只能用于“展开更多”。
8. 动画必须严格沿 edge.source → edge.target。
9. 本命角色不要被大限/流年覆盖；动态层只做 activation 高亮。
10. 页面必须在手机上可读。

## 需要完成的页面

### 1. 输入/适配
- 从现有命盘对象映射到 ZDSM schema
- 调用 `analyzeChart`

### 2. 摘要卡
显示：
- 核心发动机
- 中央处理器
- 主要输入
- 主要输出
- 长期积累
- 最大瓶颈
- 恢复节点

### 3. 主系统图
布局固定为：

```text
入口 → 发动机 → 中央处理 → 输出 → 积累
                     ↓
                   恢复
```

不要把十二宫全部摆成圆盘或蜘蛛网。

### 4. 动画
只动画：
- 主增长循环
- 恢复循环
- 入口 → 中枢

### 5. 调试面板
开发环境可展开：
- scores
- visibleNodes
- edges
- hiddenEdges
- rule version

## 验收

使用 `data/sample_chart.json` 后，页面必须：
- 识别官禄/身宫为强处理核心
- 识别田宅为重要积累节点
- 财帛应具有明显较高摩擦
- 显示主增长循环与恢复循环
- 全程无 AI API 请求
