# 紫微时域 · 核心排盘版

这是与现有 3D“紫微时域”完全独立的单盘页面，目标是优先展示可核对的排盘数据。

## 页面布局

- 顶部统一使用“命盘 / 月运 / 日时 / 解读”导航，生成后默认显示完整命盘。
- 白底十二宫格线；星曜与庙旺在上，宫名、干支、大限年龄在下，出生资料与四化流向集中在盘心。
- 运限表紧贴命盘下方；大限、流年、流月、流时横向选择，当前选项自动进入可见区；流日按农历日期排列。
- 主宫使用较深蓝色，对宫与两组三合位按浅色区分。四化箭头与颜色常显。
- 月运和日时页先显示作用链、当前结论与行动；共振、过程链、规则依据按需展开。
- “解读”包含本命结构和宫位解读；完整规则、各宫详情与权重保留，默认不全部展开。
- 新布局样式在 `layout.css`，沿用原有本地排盘与规则引擎。
- 每宫只补充当前选中运限层的宫名和流曜，不堆叠全部时间层；手机端提高了星曜状态、飞化和盘心信息字号。

## 本地命例与导出

右上角“命例 / 导出”提供另存、打开、删除、JSON 备份与导入；导入会新增记录，不覆盖原命例。出生资料、排盘口径、日期、运限层级、手动选宫和分析场景随命例一起保存。最多保存 100 条；文件仅在当前浏览器读取，不上传。

“记住本机进度”默认关闭。主动勾选后可在刷新时恢复；取消勾选会清除自动恢复记录，但不删除手动保存的命例。浏览器或网页地址不同，存储可能不同，迁移前请备份。存储不可用时会提示，不影响基础排盘。

“保存命盘 PNG”生成同一命盘数据的信息图，包含十二宫、当前层、四化列表、配色和排盘口径；与屏幕截图的排版不同。“打印当前页 / PDF”可用浏览器的“另存为 PDF”：命盘页只打印盘面与出生资料，月运、日时、解读页会展开该页的详情，打印结束恢复原展开状态。四化箭头会按打印尺寸重新定位。

## 准确性修正与边界

- 月运和日时分析均读取主星、辅星的生年四化，保留文昌、文曲、左辅、右弼的四化信息。
- 只有按本宫宫干计算并经排盘器确认的同宫飞化标为自化；运限四化返回当前主宫不自动标成自化，箭头回环与自化语义分开。
- 大限表加入起限前童限年份；落宫与四化仍由 iztro 提供，不自行推测。生日分界跨限时重新同步导航；日期转换固定用中午处理日历，不因晚子时改动所选公历日期。流日干支仍按实际所选时辰和晚子口径计算。
- 早于出生、超过十二个大限范围或上游没有有效落宫时明确报错，保留原有效选择，不悄悄换到其他年份。
- 解读摘要与 JSON 包含实际查看层级、选宫、四化来源和排盘口径；取消流时不再显示残留时辰。页面“规则完整性检查”不代表预测准确率。
- 人工联系方式继续来自打包的 P4 `config/contact.json`；未填写时明确显示尚未配置，不显示占位微信或邮箱。修改配置后需重新运行打包脚本。

## 保留的核心功能

- 公历／农历排盘与闰月选项
- 出生时辰、性别与排盘口径
- 一个传统 4×4 十二宫盘
- 主星、辅星、杂曜、庙旺和生年四化
- 命宫、身宫、命主、身主、五行局
- 长生十二神、博士十二神、将前十二神、岁前十二神
- 大限、小限和指定日期的流年、流月、流日、流时
- 命盘下方的大限 → 流年 → 农历流月 → 流日 → 流时五级选择器
- 再次点击已选运限可逐级取消：流时 → 流日 → 流月 → 流年 → 大限 → 本命；下级选中与落宫标记同步取消，主宫、三方四正和四化回到上一级。取消不改动已保存的日期，可重新选择下级。
- 闰月按设置显示为 13 项，或拆分前后半月显示为 14 项
- 选择时间后同步更新十二宫的运限宫名、流曜、四化和五色落宫标记
- 切换年、月、日、时后，自动用最深色显示该层主宫，并以三档浅色区分对宫、财帛位和官禄位
- 禄、权、科、忌四条飞化方向常显；动态运限按该层天干计算，点击宫位则按该宫宫干计算，并明确标记自化
- 十二宫均可点击，点击后显示本宫宫干四化与三方四正
- 接入 ZDSM Knowledge Base 1.5-P4-local；当前宫位同步显示宫位职责、168条主星×宫位规则、辅煞／细化星、同宫组合、庙旺表与四化语义
- 显示长生、博士、岁前、将前细节和当前时间激活层，并明确短周期不能覆盖长期结构
- 显示当前宫位相关的 P4 系统功能链，不把14条功能边叠到命盘上遮挡四化箭头
- 本地规则报告按选定范围直接匹配 P0–P4 CSV 数据，输出命中规则、置信度、推断边界、当前四化和功能链；不需要地址、密钥或模型
- P5 本月运行页默认从大限、流年、小限、流月组成作用链，显示流月三方四正、本月四化、共振节点、现实轴和行动建议
- P6 流日／流时页提供独立的“今天”和“选择日期 / 时段”入口；进入今天时默认只分析到流日，选择具体时辰后才叠加流时
- 分别展示月／日／时三方四正、上层承接、多层共振、月→日／日→时四化桥接和同星跨层四化轨迹
- 流日不能覆盖流月，流时不能覆盖流日；短周期缺少上层支持时明确降为弱信号
- 一般事务、面试、考试、谈判、写作、提交材料、出行、运动、关系与消费等事情类型只改变当前窗口的行动映射，不改变排盘结果
- 接入 ZDSM Rule Engine V1.1 的“本命系统结构”页：直接把现有命盘映射成核心发动机、处理中枢、输入、输出、积累、瓶颈与恢复节点
- 系统结构页显示静态主增长链、恢复循环和十二宫六维规则权重；取消原演示包动画，也不要求用户粘贴命盘 JSON
- 本命角色先计算并锁定，大限、流年和小限只显示激活标记，不改变本命角色
- 保留知识库来源、置信度、版本冲突和待核事项；四化表不覆盖 iztro 的实际排盘结果
- 十二宫三方四正核对表

## 刻意不做

- 3D、旋转、缩放、动画和镜头切换
- 真太阳时、出生地经纬度、时区校正、节气／非节气双四柱和日时快捷切换
- 三合／四化显示模式开关；核心关系与四化方向直接常显
- 知识账本不自动生成吉凶结论或固定事件预测
- 报告申请、个人中心和远程数据存储

## 运行

直接双击 `index.html` 即可离线打开完整版；也可以在仓库根目录启动任意静态文件服务器，然后打开：

`/examples/core-chart/`

页面随包附带 `iztro@2.6.1` 浏览器构建与生成后的 `knowledge-data.js`，不依赖 CDN，也不要求本地服务器。出生资料只在浏览器本地参与计算，不发送到服务器。

完整知识库保存在 `knowledge-base/`，原始包的 SHA-256、网页实时读取范围和本地管线边界见 `knowledge-base/ORIGIN.md`。网页使用由20张 CSV、P5 月运配置、P6 流日／流时配置和 V1.1 系统结构规则组成的本地规则包；内容更新后运行 `node build-knowledge-bundle.mjs` 即可同步 P0–P6 数据。SQLite 和 Python 专家管线作为本地资源保留，不在静态浏览器中自动执行。

浏览器回归测试位于 `tests/smoke.cjs`，P6 指定示例的规则锁定测试位于 `tests/p6-regression.cjs`。前者检查默认命盘、四项导航、宫位展开、手机横向溢出与宫内裁切、当前年份可见性、月运四化、今天入口、日时模式、系统结构与颜色联动，并记录外部请求；后者逐项核对 2026-10-10 09:00–11:00 的六层落宫、月日重复激活、日时桥接、天机跨层过程链与田宅行动输出。两项测试均不调用外部接口。

`tests/transit-toggle.cjs` 在电脑和手机尺寸核对逐级取消、下级标记清除、重新选中、键盘操作与手动点宫后的回退，并独立调用本地排盘器比对上一级主宫、三方四正与四化飞入；同时检查取消流时后进入日时页不会重新叠加流时。

`tests/accuracy-workspace.cjs` 补充 1991/1998/1992 年命例的完整生年四化传递、十二宫自化与飞回主宫的区别、童限、生日分界、农历跨年、闰月上下半月、晚子时两种口径、无效日期回滚，以及命例恢复、备份导入、PNG、打印展开和 1365/390/320 宽度验收。测试调用已有排盘器做数据一致性核对，不等于已经与所有流派、所有文墨天机设置逐盘比对。P6 指定 JSON 样例用于规则层回归，并不是独立排盘真值库。

运限计算调用 iztro 的公开 `decadalList()`、`yearlyList()`、`monthlyList()` 与 `horoscope()` API，并结合项目同级的《紫微斗数排盘算法整理》确认口径。文墨天机为闭源产品；本页只参考用户提供截图中的逐层选择交互，没有使用或声称使用其源码和私有数据。
