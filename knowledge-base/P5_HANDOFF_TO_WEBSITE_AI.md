# 直接复制给网站开发 AI 的任务说明

请把我提供的 **ZDSM P5 Monthly Runtime Supplement v1.0** 合并进现有 **ZDSM P4 Local** 项目。

要求：

1. 不接入任何 OpenAI、Gemini、Claude 或其他 LLM API。
2. 保留 P4 的所有本命分析、数据库、十二宫完整系统图和人工联系方式。
3. 新增“本月”作为高频入口，建议首页默认进入本月。
4. 使用 P5 的 `engine/monthly_runtime.py` 作为月运规则引擎。
5. 流月命宫与流月四化必须来自现有排盘器；如果没有数据，显示缺失提示，不允许模型猜。
6. 月运页面展示：大限→流年→小限→流月、本月三方四正、四化、共振节点、核心宫、机会承接、最大瓶颈、对宫拉扯、四大现实轴、本月行动。
7. 四大现实轴允许显示“低”，不要强行生成同长度内容。
8. 报告底部只保留 P4 `config/contact.json` 的人工联系方式，不增加AI问答。
9. 复用现有网站视觉系统；P5 示例 HTML 仅用于展示信息结构，不要求照搬样式。
10. 安装后按照 `docs/INSTALL_FOR_WEBSITE_AI.md` 完成验收并报告具体修改文件。

不要重写命理规则；优先复用 P4 数据层。P5 是增量补丁，不是新的独立项目。
