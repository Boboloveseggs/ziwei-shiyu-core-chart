# P6 安装说明：日运 / 时运运行引擎

## 前提

网站已经安装：
- ZDSM P4 Local
- ZDSM P5 Monthly Runtime

P6 是增量补丁，不替换 P4/P5。

## 新增能力

用户可以输入：

- 任意日期
- 可选任意两小时时段
- 可选现实场景：一般事务、面试、考试、谈判、写作、提交材料、出行、运动、关系、消费

然后系统自动生成：

1. 本命 → 大限 → 流年 → 小限 → 流月 → 流日 → 流时
2. 流月三方四正
3. 流日三方四正
4. 流时三方四正
5. 日/时四化
6. 多层重复共振
7. 跨层四化桥接
8. 同一颗星跨月/日/时的“过程链”
9. 这个时间窗口更适合做什么
10. 最需要注意哪个环节

全程不调用 AI API。

## 上游排盘器必须提供

P6 不自己猜：
- 流月命宫
- 流日命宫
- 流时命宫（用户选具体时段时）
- 流月四化
- 流日四化
- 流时四化

没有这些数据就报缺失。

## 调用

```bash
python engine/daily_hourly_runtime.py   chart.json   daily_hourly_request.json
```

渲染：

```bash
python engine/render_daily_hourly.py   output.json   P4/config/contact.json   daily-hourly.html
```

## 页面建议

新增：

```text
/monthly/{yyyy-mm}
/daily/{yyyy-mm-dd}
/daily/{yyyy-mm-dd}?time=09:00-11:00
```

用户只选日期：
- 显示到流日。

用户同时选时段：
- 继续显示流时。

## 核心规则

### 1. 日运不能脱离月运
当天结论必须说明：
“这个月本来在做什么，今天推进到哪一步。”

### 2. 时运不能脱离日运
流时只回答：
“这几个小时，当前任务更适合在哪个接口完成。”

### 3. 三方四正每层都重新计算
月、日、时分别有自己的四宫网络。

### 4. 过程链优先于吉凶加减
例如同一颗星：
`流月忌 → 流日科 → 流时禄`

解释：
`先反复/卡点 → 再整理规范 → 最终提高可用性/形成成果`

不得解释成：
`-1 +1 +1 = 吉`

### 5. 跨层桥接
如果：
- 流日四化落到流时命宫或流时三方四正

则标记为：
`day_to_hour_bridge`

说明当天主题正在向这个时段的具体执行节点转移。

### 6. 短周期权限
流日/流时只能：
- 细化
- 聚焦
- 调整执行方式

不能：
- 单独预测重大事故
- 单独断婚变
- 单独断大额破财
- 单独诊断疾病
