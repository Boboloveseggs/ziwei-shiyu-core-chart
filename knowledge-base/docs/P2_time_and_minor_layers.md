# P2 时间与细化层

## 1. 时间引擎原则

权限顺序：

本命 > 大限 > 流年 > 小限 > 流月 > 流日 > 流时

短周期只能：
- 细化
- 聚焦
- 放大已有主题

不能：
- 凭空创造长期主题
- 推翻本命或年度结构
- 单靠一颗煞星断事故、疾病、破财、婚变

## 2. 本版本能直接计算

### 大限
如果上游命盘已经包含每宫大限年龄段，则按虚岁/调用方提供年龄查宫。

### 小限
如果上游命盘已经包含每宫小限年龄列表，则查宫。

### 流年
如果上游命盘已经包含每宫流年年龄列表，则查宫。

### 长生十二神
按项目来源：
- 火局长生寅
- 木局长生亥
- 金局长生巳
- 水土局长生申
- 阳男阴女顺
- 阴男阳女逆

### 博士十二神
- 博士与禄存同宫
- 阳男阴女顺
- 阴男阳女逆

## 3. 本版本不自行计算

以下必须由上游排盘器或已锁定算法模块传入：

- 流月命宫
- 流日命宫
- 流时命宫
- 流月/流日/流时四化
- 任何流派特定飞化

原因：
项目来源当前没有提供足够完整且唯一的流月、流日、流时算法。
Skill/解释引擎不得自行猜测。

## 4. 低权重星曜

年支十四星、博士十二神、长生十二神、红鸾天喜天姚咸池等：

默认 `detail_only`。

只有当：
1. 上层结构已有同主题；
2. 当前星曜再次重复；
3. 现实中存在对应暴露条件；

才允许提升为辅助证据。

不得让：
“红鸾”单独推出恋爱，
“病符”单独推出疾病，
“大耗”单独推出大额破财，
“破碎”单独推出事故。

## 5. 2026-10-10 示例

示例把月/日/时位置作为**上游已算结果**输入。
P2 只负责：

大限福德
+ 流年子女
+ 小限交友
+ 流月夫妻
+ 流日夫妻
+ 流时田宅

然后检测：
- 同宫重复
- 上下层共振
- 短周期信号是否有上层支持
