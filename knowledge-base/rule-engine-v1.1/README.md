# ZDSM Rule Engine V1.1

一个完全不依赖 AI 的紫微斗数“系统结构图”规则引擎。

目标不是输出传统十二宫流水账，而是把一张命盘压缩成：

- 核心发动机
- 外部资源入口
- 中央处理器
- 主要输出口
- 长期积累点
- 主要瓶颈
- 恢复/调节回路
- 1 条主增长循环
- 1 条恢复循环
- 若干必要分流

然后以简洁 SVG 系统图呈现。

## 目录

- `index.html`：可直接打开的演示页
- `src/rules.js`：全部规则表
- `src/engine.js`：评分、模块识别、主循环识别
- `src/renderer.js`：SVG 上图与动画
- `src/app.js`：页面交互
- `data/sample_chart.json`：示例命盘
- `data/chart.schema.json`：输入 JSON 结构
- `tests/test_engine.html`：浏览器测试
- `RULEBOOK.md`：规则说明
- `DEPLOY.md`：部署说明
- `INTEGRATION_PROMPT.md`：直接扔给本地 AI 的集成提示词

## 最快使用

1. 解压整个目录。
2. 双击 `index.html`。
3. 粘贴命盘 JSON。
4. 点击“生成系统图”。

无需服务器、无需 npm、无需 API、无需联网。

## 设计原则

1. **同一命盘输入，结果完全确定。**
2. 权重全部写死在 `src/rules.js`，可追溯、可修改。
3. 不把权重包装成统计学概率或“准确率”。
4. 本命结构与运限覆盖分开，避免动态层污染底盘。
5. 图只显示必要节点，不画十二宫蜘蛛网。
6. 先找“系统角色”，再找“主循环”，最后画图。
7. 主图最多 8 个节点，超过则自动裁剪次要节点。
8. 空宫保留宫位功能，但不获得主星主导权。
9. 四化代表状态/流向修正，不直接等价为吉凶。
10. 三方四正只增加结构耦合，不取代本宫功能。

## 重要说明

ZDSM 是现代系统化解释框架，不是传统古籍中的原始术语，也不是经过统计验证的人格/命运预测模型。
其中星曜功能权重、宫位角色权重、连边选择阈值均属于透明的启发式规则。
