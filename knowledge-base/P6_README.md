# ZDSM P6 Daily / Hourly Runtime Supplement v1.0

这是 P4 + P5 的日运/时运补充包。

## 它解决什么

支持用户查询：

- “2026年10月10日怎么样？”
- “2026年10月10日上午9点到11点怎么样？”
- “这个时间适合面试吗？”
- “今天适合写东西还是谈合作？”
- “这个时段最容易卡在哪里？”

前提是排盘器已经计算出对应的流月/流日/流时数据。

## 不使用 AI API

P6 只运行：
- 规则库
- 三方四正
- 四化
- 时间门控
- 共振识别
- 过程链
- 场景适配模板

## 和 P5 的关系

P5 回答：
> 这个月整体在做什么。

P6 回答：
> 今天把这个月的任务推进到哪一步；如果选择某个时段，这几个小时最适合在哪个节点完成。
